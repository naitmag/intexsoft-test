
# 🏦 Bank CLI App

**Intex Bank CLI App** — консольное приложение для управления счетами клиентов и выполнения переводов между банками.  
Проект демонстрирует работу с клиентами, банками, валютами и транзакциями в интерактивном режиме через терминал.

---

## 🚀 Возможности

- CRUD-операции для **банков** и **клиентов**
- Автоматическое открытие счёта при создании клиента
- **Переводы между клиентами** одного банка без комиссии
- **Межбанковские переводы** с учётом фиксированной комиссии
- Поддержка **физических** и **юридических** лиц с разными тарифами
- **Мультивалютные счета** и конвертация при переводах
- Просмотр **балансов** и **истории транзакций**
- Сохранение и загрузка данных в/из **JSON**
- Управление через **интерактивную консоль**

---

## 🧱 Структура проекта

```
src/
└── app/
    ├── app_layer/               # Слой приложения (application layer) — бизнес-логика и команды
    │   ├── commands/            # Реализация CLI-команд и обработчиков действий пользователя
    │   ├── domain/              # Доменные сущности и бизнес-правила
    │   │   └── models/          # Классы Bank, Client, Account, Transaction
    │   └── utils/               # Утилиты и вспомогательные функции
    │
    └── infra/                   # Инфраструктурный слой (infrastructure layer)
        ├── database/            # Работа с данными (в текущей версии — JSON)
        │   └── models/          # Модели хранения и сериализации данных
        └── repositories/        # Репозитории для доступа к данным и абстракции хранилища
````

## ⚙️ Установка и запуск

### 🐳 Запуск через Docker (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/naitmag/intexsoft-test.git
   cd intexsoft-test


2. Постройте и запустите контейнер:

   ```bash
   docker-compose up
   ```

3. После запуска откройте новый терминал и подключитесь к контейнеру:

   ```bash
   docker exec -it app python src/main.py
   ```

4. Введите `help`, чтобы увидеть список всех доступных команд.

---

### 💻 Альтернативный запуск (локально без Docker)

1. Установите зависимости:

   ```bash
   pip install poetry
   poetry install
   ```

2. Запустите приложение:

   ```bash
   python src/main.py
   ```

## 💾 Хранение данных

Все данные (банки, клиенты, счета, транзакции, валюты) сохраняются в JSON-файл `data.json`.
Пример структуры:

```json
{
  "banks": [],
  "clients": [],
  "accounts": [],
  "transactions": []
}
```

## 🧠 Архитектура и подход

Архитектура основана на принципах Clean Architecture: бизнес-логика изолирована от инфраструктуры, а зависимости направлены от внешнего слоя к внутреннему.

* Используется **ООП** с разделением по сущностям (`Bank`, `Client`, `Account`, `Transaction`)
* Паттерн **Command** — для регистрации и обработки CLI-команд
* Паттерн **Repository / Storage** — для абстракции работы с JSON
* Возможность расширения (например, подключение БД вместо JSON)
* Гибкая структура для добавления новых команд
